# PTCG autonomous research loop

1. `AGENTS.md`, 최신 저널, 가설 원장을 읽는다.
2. 상태와 최신 외부 맥락을 동기화한다.
3. 가설 하나를 고르고 성공 기준·상대 묶음·표본 수를 먼저 적는다.
4. 후보 디렉터리 하나만 바꾼다.
5. smoke → quick → full 순서로 평가하고 `results.tsv`에 남긴다.
6. 비결정적 엔진의 한 번 결과로 승격하지 않는다.
7. 반복 개선과 회귀 없음이 확인되면 현재 best를 보관하고 후보를 루트로 승격한다.
8. 패키징 검증 후 사용자 승인이 있을 때만 제출한다.

외부 제출, 계정 변경, Competition Data 공개가 다음 행동이면 중단하고 사용자에게 확인한다.
