# H-034 미러 상대 리스트 재구성 (2026-08-12)

목표: H-030 마이닝에서 드러난 미러(Dudunsparce/Alakazam) 열세(19승 34패)의 리스트 요인을 정량화하고, 승자 리스트를 재구성해 덱 교체 후보를 만든다. **분석 전용 — 기존 후보 미수정, 제출 없음.**

## 방법

`data/raw/episodes/h024b_ladder/`의 미러 53경기에서 상대 좌석의 **완전한 60장 덱**을 추출했다. 핵심 발견: replay의 step 0 visualize(덱 제출 액션)에 **양측 60장 리스트가 원문 그대로 들어 있다** — 관측 하한 재구성이 불필요하고, 60/60장이 전부 확인된다(하한 합산 = 60, 미관측 슬랙 0). 동일 시그니처로 클러스터링 후 대전 성적·상대 레이팅으로 랭킹했다.

## V1 = 승자 리스트 (60장 전부 관측, 슬랙 0)

`candidates/_h034_proposed_deck.csv`로 저장. 우리 h024b 리스트와의 diff:

**IN (+9)**: Fezandipiti ex(140)×1, Shaymin(343)×1, Dunsparce70(305) +2(→3), Enhanced Hammer(1081) +1(→4), Enriching Energy(13)×1, Nighttime Mine(1266)×2
**OUT (−9)**: Dunsparce60(65) −2(→0), Dudunsparce(66) −2(→2), Night Stretcher(1097) −2(→1), Lillie's Determination(1227) −1(→0), Neutralization Zone(1247) −1(→0)

구조적 의미:
- **basic 7 → 9장** (Abra4 + Dunsparce70×3 + Fezandipiti ex + Shaymin) — H-030의 bench-out 돈크 36패(전체 패배의 37%)를 직접 겨냥. Dunsparce60(HP60)을 전부 HP70판으로 승급.
- **Dudunsparce 4 → 2장** — 드로 특성 의존 축소. H-030 deck-out 패턴(14패)과 정합: 필드 승자들은 애초에 덜 태운다.
- **Hammer 4 + Nighttime Mine 2** — 미러·특수에너지 메타 저격(우리 Telepath도 맞지만 상대가 더 아픔). Enriching Energy는 Hammer 표적이 되는 대신 드로 부착 가치.
- Fezandipiti ex는 유일한 멀티프라이즈 리스크(2프라이즈)이자 특성 드로 엔진.

## fork_policy 호환성 (candidates/h030_deckout_guard/fork_policy.py 기준)

V1 신규 카드 전부가 **명명 상수 + 가중치 + 능력 로직**으로 이미 구현되어 있다:
- `Fezandipiti_ex = 140`: play_fez 20080, ability_fez 38066, 벤치·능력 사용 로직 다수
- `Shaymin = 343`: play_shaymin 19807, 상대 물/Grimmsnarl 조건 로직
- `Enriching_Energy = 13`: enriching_1st/2nd 가중치, 부착 로직
- `Nighttime_Mine = 1266`: `OUR_STADIUMS` 멤버, mine_counter 18495
- `Dunsparce305`: 명시 상수 존재. Enhanced Hammer 4장째·기존 카드는 당연 호환.
- **정책 미참조(위험) 카드: 0장.** 역으로 우리가 쓰는 Lillie's Determination(1227)·Neutralization Zone(1247)을 빼는 방향이므로 정책 커버리지는 오히려 원상복귀에 가깝다.

결론: **V1은 fork_policy(romanrozen/jazivxt 계보)의 원본 리스트이고 우리 deck.csv가 축소 변형**이었을 가능성이 높다. 정책-리스트 정합성 리스크는 사실상 없음.
