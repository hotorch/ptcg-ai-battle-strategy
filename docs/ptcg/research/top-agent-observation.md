# 상위권 에이전트 관찰 연구 (2026-08-14, D-2 착수)

사용자 제안: "상위권 에이전트끼리 주고받는 경기 수백 판을 관찰 → 패턴 분석 → 아이디어 발굴 → 적용."

## 데이터 소스

- 공식 **Daily Top Episodes Datasets** (Discussion 709160, 일 1회 00:10 UTC경 공개, ~740MB/일): 상위 레이팅 경기 리플레이 전량. `data/raw/episodes/pokemon-tcg-ai-battle-episodes-YYYY-MM-DD.zip`.
- 기존 도구: `mine_episodes.py deck-stats`(덱 시그니처·승률 집계), `mine_episodes.py extract`(특정 덱 경기 추출), `distill_replays.py`(선택률 표 + held-out 일치율).
- 1주차 증류 연구(H-006R~H-020)와 같은 파이프라인, 목적만 변경: 모방 학습이 아니라 **관찰 정보**.

## 질문 3개 (D-2 우선순위순)

1. **최종 풀 메타 예측**: 상위권(최신 데일리의 고레이팅 경기)에서 아키타입 분포와 상성표는? → 우리 h024b(Alakazam, 구리스트)의 최종 풀 노출 추정. 잠금 결정의 마지막 점검.
2. **상위 Alakazam 파일럿과의 행동 차이**: 같은 덱을 모는 1000+ 에이전트의 결정과 우리 정책의 argmax를 리플레이 위에서 비교(일치율 + 괴리 지점 클러스터). 괴리가 특정 상황(초반 셋업, 리트리트, 에너지 관리)에 몰리면 그것이 "다음 수선 후보"다.
3. **상위권의 대-Grimmsnarl 대응**: 상성 폴라리티 판정(우리 33%)이 상위 Alakazam 파일럿에게도 성립하는가? 그들도 지면 → 상성 확정(수선 불가 재확인). 그들은 이긴다 → 행동 차이에서 배울 것이 있다.

## 적용 원칙 (H-028 교훈 유지)

- 관찰 → 잠금 결정·리스크 평가에는 즉시 반영 가능.
- 정책 변경은 D-2에는 원칙적으로 금지(게이트+리플레이 회귀 비용). 예외: 질문 2에서 **부수 피해 없는 국소 수선**이 발견되고 리플레이 회귀로 검증 가능한 경우만.
- 어떤 경우든 카운터 튜닝(특정 덱 겨냥 가중치)은 금지.

핵심 판독:

1. **점유율 1·3위(Grimmsnarl, Alakazam)는 군중 선택이지만 상위 풀에서 승률 41~44%로 동반 최하위.** 상위 10위권 팀들은 Dragapult ex·Meganium·Slowking·Mega Lucario를 몬다 (승률 55~66%).
2. **가위바위보 삼각 구조**: Alakazam(우리)은 Grimmsnarl에게 먹히고(실측 33%), Grimmsnarl은 Dragapult/Meganium 티어에게 먹힌다(상위 풀 41%). 우리 레이팅이 오를수록 Grimmsnarl 노출(상위 게임의 23%)이 커지는 것이 **우리 800~845 천장의 구조적 메커니즘**.
3. **V1 리스트(정확 일치, 871게임)의 상위 풀 승률 41.2%** — 26팀 합의 리스트도 아키타입 자체의 상위 풀 열세는 못 바꾼다. 구리스트는 상위 풀에서 아예 관측 안 됨(하위 밴드 전용).
4. 점유율 가중 우리 기대 승률(상위 풀) ≈ 45~48% — **실버 밴드(915+)는 이 덱으로는 조종 품질만으로 도달 불가능**하다는 정직한 결론. 브론즈 밴드(~845)는 꼬리 운으로 가능(실증 844.7).
5. D-2 덱 교체는 기각: 정책 전체가 Alakazam 카드별 수제 가중치로 구성되어 있어 이식 불가, 게이트 비용도 감당 불가. **잠금 = h024b 유지, 목표 밴드 = 브론즈 꼬리, 실버는 상위 꼬리 운.**
6. Writeup 1급 재료: "군중 아키타입의 상위 풀 역설(most-played = worst-performing)"과 "레이팅 상승에 따른 메타 노출 변화가 만드는 천장" — 과적합·일관성 루브릭에 직결.

## 결과 2 — 대-Grimmsnarl 심층 (284경기) → H-036 도출

- 상위 Alakazam의 대-Grimmsnarl 승률 **48.9%** (우리 실전 33%, n=27). 퍼스트블러드 잡으면 80% 승 / 내주면 38%.
- 승리 파일럿의 첫 KO = **t5~6, 70HP 셋업 몬**(진화 전). 에너지 억제는 100% KO 경유(승자 356 vs 패자 188 에너지 제거) — Grimmsnarl은 기본 다크 에너지만 써서 해머류 무용.
- 우리 정책 코드 원인: 가스트킬 기회에 Boss's Orders(2262)가 드로 서포터(Lana 4249 등)에 밀림 → **H-036 tempo boss** (조건부 boss_kill_now=6000, 상대 불문). 리플레이 21,975결정 65/65 의도 플립, 게이트 3종 통과(미러 50.0%, meta0d 85.0%, 프록시 100%). 상세: `docs/ptcg/journal/2026-08-14.md`.

판정:

1. **"이른 첫 KO = 승리" 방향성이 전 매치업에서 일관** (역전 사례 0) — H-036의 방향은 매치업 과적합이 아님. 미러에선 심지어 핵심 승리 행동(50HP Abra 스나이프)과 정확히 일치.
2. **제2 패턴 발견: "2프라이즈(ex)를 먼저 헌납하는 것"이 전 매치업 공통 패자 행동** (Grimm 24%, Lucario 21%, Dragapult 61%, Slowking 82%). H-036은 이를 악화시키지 않음 — 발동 조건의 어태커가 1프라이즈 Alakazam(140HP)이므로 ex 노출 증가 없음. ex 노출 축소 자체는 셋업 로직 전반에 걸친 대수술이라 D-2에 부적합, **차기 과제로 기록**.
3. **Dragapult 24.9%가 상위 풀의 진짜 벽** (점유 17.2% × 승률 25%) — Grimmsnarl(48.9%)보다 심각. 우리 밴드(~700-750)엔 Dragapult가 적어 현 체감이 없지만, 컷권(850+)으로 오를수록 노출 증가. D-2에 수선 불가능하며, "이 덱의 구조적 천장" 서사의 핵심 증거로 Writeup에 반영.
