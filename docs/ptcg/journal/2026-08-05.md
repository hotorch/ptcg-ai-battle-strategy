## 배운 것

- CABT PyPI wheel은 로컬 엔진을 포함하지만 제출용 typed SDK의 `api.py`, `utils.py`는 포함하지 않는다.
- 공식 sample SDK의 Linux `libcg.so`는 macOS에서 실행할 수 없어 로컬 검증용 dylib와 제출용 so를 분리해야 한다.
- CABT RNG를 공식적으로 고정할 방법이 없어 Kaggriculture식 동일-seed 결정론 평가를 재사용하면 안 된다.
- Kaggle raw Python loader는 `__file__`을 정의하지 않는다.
